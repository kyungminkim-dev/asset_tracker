# 개인정보 수집·이용 동의

{{운영자}}(이하 "운영자")는 {{서비스명}} 회원가입과 서비스 제공을 위해 아래와 같이 개인정보를 수집·이용합니다.

## 1. 수집 항목 (필수)

- **계정 정보**: 구글 또는 카카오 계정의 고유 식별자, 닉네임(이름), 프로필 사진, 이메일 주소(구글·카카오가 제공하는 경우)
- **증권사 연결 정보**: 증권사 API 키(App Key, App Secret, Client ID, Client Secret 등), 계좌번호, 계좌 이름
- **자산 정보**: 보유 종목명·종목코드, 수량, 평균 매입가, 현재가, 평가금액, 예수금, 이를 원화로 환산한 금액과 날짜별 기록
- **직접 입력 정보**: 회원이 직접 입력한 계좌 이름과 보유 종목 정보
- **서비스 이용 기록**: 접속 일시, IP 주소, 로그인 기록

## 2. 수집·이용 목적

- 회원 식별, 가입 의사 확인, 로그인 유지
- 증권사 API를 통한 회원 본인의 잔고 조회
- 여러 계좌의 자산 합산, 기간별 자산 변화 기록 및 표시
- 서비스 오류 확인, 부정 이용 방지, 문의 응대

## 3. 증권사 API 키의 보관

- API 키는 회원 본인의 잔고를 조회하는 데에만 사용합니다. **주문이나 출금에는 사용하지 않습니다.**
- API 키는 AES-256-GCM 방식으로 암호화하여 서버에 저장하며, 앱(휴대폰)에는 저장하지 않습니다.
- 잔고 조회 시 API 키는 해당 증권사의 인증 서버로만 전송됩니다.
- 회원은 언제든지 연결을 해제할 수 있으며, 해제하면 해당 API 키는 즉시 삭제됩니다.

## 4. 보유 및 이용 기간

- **회원 탈퇴 시까지** 보유하며, 탈퇴하면 즉시 파기합니다.
- 다만 관련 법령에 따라 보관이 필요한 정보는 아래 기간 동안 보관합니다.
  - 서비스 접속 기록: 3개월 (통신비밀보호법)

## 5. 동의를 거부할 권리

회원은 개인정보 수집·이용에 동의하지 않을 권리가 있습니다. 다만 위 항목은 서비스 제공에 꼭 필요한 정보이므로, 동의하지 않으면 회원가입과 서비스 이용이 제한됩니다.

자세한 내용은 개인정보 처리방침에서 확인할 수 있습니다.
