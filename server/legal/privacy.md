# {{서비스명}} 개인정보 처리방침

{{운영자}}(이하 "운영자")는 「개인정보 보호법」 등 관련 법령을 준수하며, 이용자의 개인정보를 다음과 같이 처리합니다.

## 1. 개인정보의 처리 목적

운영자는 다음 목적을 위해 개인정보를 처리하며, 목적이 바뀌는 경우 미리 동의를 받습니다.

- 회원 가입과 관리: 회원 식별, 가입 의사 확인, 로그인 유지, 탈퇴 처리
- 서비스 제공: 증권사 API를 통한 본인 잔고 조회, 자산 합산, 기간별 자산 변화 기록과 표시
- 서비스 개선과 보안: 오류 확인, 부정 이용 방지, 문의 응대

## 2. 처리하는 개인정보 항목

- **계정 정보**: 구글 또는 카카오 계정 고유 식별자, 닉네임, 프로필 사진, 이메일(제공되는 경우)
- **증권사 연결 정보**: 증권사 API 키, 계좌번호, 계좌 이름
- **자산 정보**: 보유 종목, 수량, 매입가, 현재가, 평가금액, 예수금과 날짜별 기록
- **자동 수집 정보**: 접속 일시, IP 주소, 로그인 기록

운영자는 주민등록번호, 증권사 로그인 비밀번호, 공동인증서를 수집하지 않습니다.

## 3. 개인정보의 보유 및 이용 기간

- 회원 정보와 서비스 이용 정보는 **회원 탈퇴 시까지** 보유합니다.
- 관련 법령에 따라 보관이 필요한 정보는 해당 기간 동안 보관합니다.
  - 서비스 접속 기록: 3개월 (통신비밀보호법)

## 4. 개인정보의 파기

- 회원이 탈퇴하면 계정 정보, 증권사 API 키, 연결 계좌, 자산 기록을 **즉시** 데이터베이스에서 삭제합니다.
- 연결 계좌를 해제하면 해당 API 키를 즉시 삭제합니다. 이미 저장된 과거 자산 기록은 탈퇴 전까지 유지됩니다.
- 전자적 파일 형태의 정보는 복구할 수 없는 방법으로 삭제합니다.

## 5. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 이용자가 연결을 요청한 증권사에 잔고를 조회하기 위해 해당 증권사가 이용자에게 발급한 API 키로 인증하는 것은 이용자 본인의 요청에 따른 것입니다.

- 위탁 업무: 서버 운영 및 데이터 보관

## 8. 개인정보의 안전성 확보 조치

- **암호화**: 증권사 API 키와 접근 토큰은 AES-256-GCM으로 암호화하여 저장합니다. 로그인 세션 토큰은 원문 대신 해시값만 저장합니다.
- **전송 구간 보호**: 앱과 서버, 서버와 증권사 사이의 통신은 암호화된 연결(HTTPS)을 사용합니다.
- **접근 통제**: 각 회원은 자신의 정보에만 접근할 수 있도록 서버에서 확인합니다.
- **최소 수집**: 증권사 로그인 비밀번호, 주민등록번호 등은 수집하지 않습니다.

## 9. 이용자의 권리와 행사 방법

- 이용자는 언제든지 자신의 개인정보를 열람, 정정, 삭제하거나 처리 정지를 요구할 수 있습니다.
- 앱의 **설정 > 회원 탈퇴**로 모든 정보를 직접 삭제할 수 있으며, **계좌** 화면에서 연결을 해제할 수 있습니다.
- 그 밖의 요청은 아래 개인정보 보호책임자에게 연락하면 지체 없이 처리합니다.

## 10. 개인정보 자동 수집 장치
