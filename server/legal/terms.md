# {{서비스명}} 서비스 이용약관

## 제1조 (목적)

이 약관은 {{운영자}}(이하 "운영자")가 제공하는 {{서비스명}}(이하 "서비스")의 이용과 관련하여 운영자와 회원의 권리, 의무 및 책임 사항을 정하는 것을 목적으로 합니다.

## 제2조 (정의)

1. **서비스**: 회원이 연결한 증권 계좌의 보유 주식, 예수금 등 자산 정보를 한곳에 모아 보여주고, 기간별 변화를 확인할 수 있게 하는 조회 서비스를 말합니다.
2. **회원**: 이 약관에 동의하고 구글 또는 카카오 계정으로 가입하여 서비스를 이용하는 자를 말합니다.
3. **연결 계좌**: 회원이 서비스에 등록한 증권사 계좌를 말합니다. 증권사 API로 자동으로 불러오는 계좌와 회원이 보유 종목을 직접 입력하는 계좌가 있습니다.
4. **API 키**: 증권사가 회원 본인에게 발급한 Open API 인증 정보(App Key, App Secret, Client ID, Client Secret 등)를 말합니다.

## 제3조 (약관의 게시와 변경)

1. 운영자는 이 약관을 서비스 화면에 게시합니다.
2. 운영자는 관련 법령을 위반하지 않는 범위에서 이 약관을 변경할 수 있습니다.
3. 약관을 변경하는 경우 시행일 7일 전부터 서비스 화면에 공지합니다. 회원에게 불리한 변경은 시행일 30일 전부터 공지합니다.
4. 회원이 변경된 약관에 동의하지 않으면 서비스 이용을 중단하고 탈퇴할 수 있습니다. 시행일 이후에도 서비스를 계속 이용하면 변경된 약관에 동의한 것으로 봅니다.

## 제4조 (회원가입)

1. 회원가입은 이 약관과 개인정보 수집·이용에 동의한 뒤 구글 또는 카카오 계정으로 인증하여 완료됩니다.
2. 만 14세 미만은 가입할 수 없습니다.
3. 다른 사람의 계정으로 가입한 경우 운영자는 이용을 제한하거나 회원 자격을 박탈할 수 있습니다.

## 제5조 (서비스의 내용)

1. 서비스는 다음 기능을 제공합니다.
   - 증권사 API 또는 직접 입력을 통한 보유 자산 조회
   - 여러 계좌의 자산 합산 및 해외 주식의 원화 환산
   - 매일 자산 기록 저장 및 기간별 자산 변화 표시
2. **서비스는 조회 전용입니다.** 주식 매매 주문, 투자 자문, 투자 권유, 투자 일임을 하지 않습니다.
3. 서비스가 보여주는 손익, 수익률, 비중 등은 참고용 정보이며 투자 판단의 근거로 제공하는 것이 아닙니다.

## 제6조 (정보의 정확성과 책임의 한계)

1. 서비스의 자산 정보는 증권사 API 응답, 회원이 직접 입력한 값, 외부 환율 정보(유럽중앙은행 기준환율)를 바탕으로 계산합니다.
2. 증권사 시스템 점검, API 응답 지연·오류, 환율 차이 등으로 실제 잔고와 다르게 표시될 수 있습니다.
3. 동기화에 실패한 계좌는 직전에 저장된 값으로 표시될 수 있으며, 이 경우 화면에 "이전 데이터"로 표시합니다.
4. 정확한 잔고와 거래 내역은 해당 증권사에서 확인해야 합니다. 회원의 투자 판단과 그 결과에 대한 책임은 회원 본인에게 있습니다.

## 제7조 (회원의 의무)

1. 회원은 **본인 명의의 계좌와 본인에게 발급된 API 키만** 등록해야 합니다.
2. 회원은 각 증권사의 Open API 이용약관을 확인하고 준수해야 합니다.
3. 회원은 API 키가 유출되었거나 유출이 의심되면 즉시 해당 증권사에서 키를 폐기·재발급하고, 서비스의 연결을 해제해야 합니다.
4. 회원은 서비스를 이용하여 법령이나 이 약관에 위반되는 행위를 해서는 안 됩니다.

## 제8조 (서비스의 변경과 중단)

1. 운영자는 증권사 API 정책 변경, 시스템 점검, 설비 장애 등의 사유로 서비스의 전부 또는 일부를 변경하거나 중단할 수 있습니다.
2. 특정 증권사가 API 제공을 중단하거나 조건을 변경하면 해당 증권사의 자동 연결 기능이 중단될 수 있습니다.
3. 운영자는 서비스를 종료하려는 경우 30일 전에 서비스 화면에 공지합니다.

## 제9조 (회원 탈퇴)

1. 회원은 언제든지 앱의 **설정 > 회원 탈퇴**에서 탈퇴할 수 있습니다.
2. 탈퇴하면 연결된 증권사 API 키, 직접 입력한 종목, 자산 기록 등 회원의 정보가 즉시 삭제되며 복구할 수 없습니다. 다만 관련 법령에 따라 보관해야 하는 정보는 해당 기간 동안 보관합니다.

## 제10조 (면책)

1. 운영자는 천재지변, 증권사 또는 통신사의 장애 등 운영자가 통제할 수 없는 사유로 서비스를 제공할 수 없는 경우 책임을 지지 않습니다.
2. 운영자는 회원의 귀책사유(API 키 관리 소홀, 타인 계정 사용 등)로 발생한 손해에 대해 책임을 지지 않습니다.
3. 운영자는 서비스에 표시된 정보를 근거로 회원이 한 투자 판단과 그 결과에 대해 책임을 지지 않습니다. 다만 운영자의 고의 또는 중대한 과실로 인한 손해는 그러하지 않습니다.

## 제11조 (분쟁 해결)

1. 서비스 이용과 관련한 문의는 {{연락처}}로 할 수 있습니다.
2. 이 약관과 서비스 이용에 관한 분쟁에는 대한민국 법을 적용하며, 소송은 민사소송법에 따른 관할 법원에 제기합니다.
